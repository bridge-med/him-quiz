# 変更履歴

## v8（2026-11）— 専門課程 科目試験対策版

### 科目と問題バンク
- 科目を日本病院会の募集要項にある**専門課程の12科目**に合わせて組み直した（旧版の「全12章」は基礎課程の内容も混ざっていた）。基礎課程の問題は「基礎課程（参考）」として分けた。根拠は `docs/exam-research.md`。
- 問題データを `index.html` の埋め込みから `bank/questions/科目.json` に分けた。公開用の `data/bank.js` は `tools/build.mjs` が生成し、`--check` で生成元との乖離を検出する（CI・デプロイ前に実行）。
- 全問に永続ID、科目、サブトピック、形式、難易度、根拠資料（名称・URL・該当箇所・引用）、基準時点、検証状態、検証日を持たせた。関連問題IDはビルド時に同じ科目・サブトピックの検証済み問題から算出する。
- 旧版の360問をすべて監査し直した（正答を見ない独立解答＋領域監査＋修正分の独立再監査＋引用の機械照合）。結果は `docs/audit-report.md`・`docs/legacy-changes.md`。
- 新しい問題を、一次資料（法令・厚生労働省・国立がん研究センター等）を引用して作り、別のエージェントが検証した。公開するのは `verified` だけ。
- 5択、誤っているものを選ぶ問題、組み合わせ、計算、症例、ICD-10、退院時要約（1つの架空症例から複数問）に対応。
- 正答位置の偏り（旧版は64%が「A」）を、選択肢と解説を同時に並べ替えて解消した。

### 学習機能
- すべてのモード（科目別・ランダム・模擬試験・誤答復習など）の解答を問題IDで記録する。問題ごとに解答回数、正答・誤答回数、連続正答、最終解答日時、習熟段階、解答時の自信、次回復習推奨日を保存。
- 誤答の復習は、**異なる2日に正答するまで**リストから外さない。勘で正解した問題もリストに入れる。
- 解答後に「自信あり／迷った／勘」を任意で記録。迷った・勘の問題は早めに再出題する。
- スキマ時間（5・10・20問）と「今日の学習」: 復習対象と未演習を半分ずつ、弱いサブトピックの類題を優先。
- 弱点集中: サブトピックごとの直近の正答率から弱点を判定し、誤答と未演習の類題を出す。
- 模擬試験: 全範囲50問60分（従来）に加えて、科目別、ICD-10集中、退院時要約集中。試験中は正誤・解説を出さず、見直しフラグ、解答状況の一覧、途中終了、時間切れの自動採点、終了後の全問見直しに対応。本アプリ独自の形式であることを明示。
- ダッシュボード: 総問題数、演習済み、未演習、網羅率、初回正答率、直近正答率、累積正答率、習熟済み、復習対象、科目別・サブトピック別の習熟度、模擬試験の推移、試験日までの残り日数と1日あたりの目安。
- 解説に根拠資料（リンク）と基準時点、問題IDを表示。類題を解くボタン。

### 学習データの移行と保護
- 旧版の「章ID＋配列の位置」で保存された誤答リスト・ブックマークを、永続IDへ自動で移す。移行前のデータは丸ごと退避し、「バックアップから復元」で戻せる。章別スコアは問題単位に分けられないため「旧版の記録」として残す。
- 取り込み・全リセットの前にも自動でバックアップを取る。旧版の書き出しファイルも取り込める（自動で移行）。
- 端末に保存できない環境（プライベートブラウズ等）では警告を出す。
- 途中のセッション（模擬試験を含む）を保存し、再読み込み後に再開できる。
