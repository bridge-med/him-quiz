## 2. 検証の方法（役割の分離）

どの問題も、作った（または旧版を書いた）エージェント自身の判断では verified にしない。役割ごとに別のエージェントを起動し、記録を残した。

| 役割 | 担当 | やったこと |
|---|---|---|
| 出題範囲調査 | 調査エージェント6体＋現場 | 日本病院会の募集要項等で範囲を確認（`docs/exam-research.md`）。法令52本・厚生労働省等の文書 約400件を取得し、テキスト化して登録簿にした（`docs/sources.md`） |
| 問題生成 | 生成エージェント（分野ごと） | 一次資料の該当箇所を開いてから作問。根拠は資料ID・URL・該当箇所・**原文どおりの引用**で記録 |
| 正答検証 | ブラインド解答エージェント（**生成と別のモデル**） | 正答・解説を除いた問題だけを解き、正答・自信・曖昧さを記録 |
| 選択肢・解説検証／領域監査 | 監査エージェント（ICD-10専門、法令・制度、統計、医療管理・情報、実務・DPC・がん登録の5領域） | 正答の一意性、誤答が明確に誤りか、問題文の曖昧さ、正誤の指定、解説と正答の一致、根拠が正答を支持するか、基準時点、ICDの版と分類、計算を確認。pass / fix / reject を判定 |
| 修正分の再監査 | 別の監査エージェント | 修正された問題を、まず正答を見ずに解き、その後に全項目を確認。pass / provisional / reject（再監査者は修正しない） |
| 重複・品質監査 | スクリプト＋監査エージェント | 文字3-gramの類似度で近い組を抽出し、重複か類題かを判定。正答位置の偏りを集計 |
| 機械検査 | `tools/validate.mjs`・`tools/build.mjs` | スキーマ、4〜5択、選択肢別解説の数、否定形の指定と問題文の一致、**引用が資料本文に実在するか**（正規化して照合）、ICDコードが基本分類表（2013年版）に存在するか、計算問題の式と正答の一致 |

**verified の条件**（`tools/merge-results.mjs` が機械的に判定）

- 監査が pass で、ブラインド解答が正答と一致し、機械検査に通ること
- 監査で fix になった問題は、独立した再監査が pass で、再監査者のブラインド解答も正答と一致し、機械検査に通ること
- それ以外（ブラインド解答と不一致のまま、再監査が provisional、機械検査で不合格など）は provisional。誤り・曖昧・根拠不足・古い・重複は rejected

各問題の `verification` に、日付・手順（method）・担当（roles）・監査記録の場所（log）・監査メモ（notes）を残した。監査記録の原本は `bank/audit/` にある（ブラインド解答、監査の判定と根拠、再監査）。

## 5. 既存360問で見つかった主な誤りの型

旧版の問題は出典がなく、監査で多くの修正が必要だった。修正・除外の全件は `docs/legacy-changes.md`。代表的な型:

- 正答そのものの誤り（例: ICD-10（2013年版）の章数を21章としていた。正しくは22章）
- 正答は合っていても、誤答の解説や「ポイント」に誤った記述（剣印・星印の使い方、コードの範囲、主傷病名と医療資源病名の混同など）
- 制度改正前の名称・数値（社会保険診療報酬支払基金の改組、令和8年度診療報酬改定、安全管理ガイドラインの版など）
- 誤答が明らかに無関係で学習効果が低い（4択→根拠のある5択に作り直し）
- 科目の誤分類（DPC・がん登録を国際統計分類Ⅱに、コーディングを診療情報管理Ⅱに置いていた）

## 6. 重複・類似の監査

問題文＋正答の文字3-gramの類似度（Jaccard 0.6 以上）で抽出した組と、再監査で指摘された組を確認し、同一問題と判断した 5 問を除外した（一覧は `bank/overrides.json`）。同じ知識を別の角度から問う類題は残した。

- 死亡診断書（死体検案書）記入マニュアル 令和8年度版

## 8. 限界と注意

- 監査はAIエージェントが一次資料を照合して行った。役割と使うモデルを分け、引用の実在は機械で確かめたが、人の専門家による査読ではない。誤りを見つけたら問題IDを添えて知らせてほしい。
- 科目試験の問題数・時間・形式は公開資料で確認できなかった。模擬試験は独自の形式。
- 公式テキスト・練習問題は使っていないため、テキスト固有の言い回しや範囲の細部とずれる可能性がある。
- 法令・制度は 2026-11-24 時点の取得内容に基づく。以後の改正は反映していない。
